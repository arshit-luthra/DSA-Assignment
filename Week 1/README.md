# UCS301 Data Structures – Week 1

## Lab Assignment 1 – Arrays

This folder contains the solutions for **Lab Assignment 1 (Week 1)** of the **UCS301 Data Structures** course.

The assignment focuses on basic operations on one-dimensional and two-dimensional arrays using C++.

## Programs

### 1. Menu-Driven Array Operations

A menu-driven program demonstrating the following array operations:

* Create
* Display
* Insert
* Delete
* Linear Search
* Exit

**File:** `Menu.cpp`

### 2. Remove Duplicate Elements

Program to remove duplicate elements from an array so that the array contains only unique elements.

**File:** `Remove_duplicate.cpp`

### 3. Rotate 1-D Array

Program to rotate a one-dimensional array by `K` positions.

The program performs:

* Left Rotation
* Right Rotation

**File:** `Rotate_1d_Array.cpp`

### 4. Reverse an Array

Program to reverse the elements of an array.

**File:** `Reverse_Array.cpp`

### 5. Matrix Multiplication

Program to perform multiplication of two matrices.

**File:** `Matrix_Multiplication.cpp`

### 6. Matrix Transpose

Program to find the transpose of a matrix.

**File:** `Matrix_Transpose.cpp`

### 7. Sum of 2-D Array

Program to find the sum of every row and every column in a two-dimensional array.

**File:** `Sum_2d_Array.cpp`

**C++**

## How to Run

Compile any program using a C++ compiler.

Example:

```bash
g++ Menu.cpp -o Menu
```

Run the program:

```bash
./Menu
```

For Windows, the generated executable can be run using:

```bash
Menu.exe
```
